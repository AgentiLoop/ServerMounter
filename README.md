# ServerMounter

A simple macOS utility that lets a user log in to an Apple File Server (AFP/SMB). Keeps it simple for non-technical users.

🤖 **Built by the makers of [Agent!](https://github.com/AgentiLoop/Agent)**, an autonomous macOS agent. 🌐 [agentiloop.ai](https://agentiloop.ai)

## Build

1. Open `ServerMounter.xcodeproj` in Xcode.
2. Select the **ServerMounter** scheme and press **Run** (⌘R).
